Hướng Dẫn Từng Bước Đưa Quái Vật / Boss Đã Thiết Kế Lại Vào Game

Bước 1: Thiết Kế & Kiểm Tra Trực Tiếp Trong Studio

Dùng thanh trượt màu sắc, bán kính, hoặc sửa trực tiếp code vẽ trong tab "Mã Nguồn Canvas". Bấm nút "⚡ ÁP DỤNG CODE NGAY" để kiểm tra xem trước 360 độ và dáng đi.

Bước 2: Sao Chép Code Đã Tinh Chỉnh

Bấm nút "Sao Chép Hàm Vẽ" ở thanh trên cùng (hoặc copy trong tab mã nguồn).

Bước 3: Mở file game và dán đè vào vị trí hàm cũ

Mở file alien-shooter-fullstack/frontend/index.html:

  • Hàm 5 quái thường: drawXenomorphMonsterProcedural (dòng 24046 đến 25167).
  • Các hàm Boss: từ dòng 23250 đến 25612.
  • Cấu hình thông số (màu sắc/máu/tốc độ): tại ENEMY_TYPES (dòng 6894 đến 6920).
Bước 4: Chạy lệnh Build tự động

Mở terminal PowerShell trong thư mục dự án và chạy:

powershell -ExecutionPolicy Bypass -File .\build_minified.ps1

Hệ thống sẽ tự động nén, tối ưu hóa và đồng bộ sang toàn bộ thư mục dist/ và root index.html. Khởi động game sẽ thấy quái mới tức thì!

HƯỚNG DẪN ĐƯA QUÁI VẬT VÀO LẠI GAME

Toàn bộ 15 quái vật và Boss trong game Alien Shooter được kết xuất theo cơ chế Toán học Vector Canvas 2D (Procedural Rendering). Studio độc lập này giúp bạn thiết kế tự do mà không bao giờ sợ làm vỡ game chính.

Quy trình 1-Click đưa code vào game:
  1. Chọn quái và tinh chỉnh thông số hoặc code trong Studio.
  2. Bấm nút "Sao Chép Hàm Vẽ" ở thanh menu trên cùng.
  3. Dán vào file alien-shooter-fullstack/frontend/index.html tại hàm tương ứng.
  4. Chạy file .\build_minified.ps1 trên PowerShell.
  5. Mở game và thưởng thức quái vật mới với đầy đủ RAM ImageBitmap tăng tốc VGA!
